# Getting started with Helios

> Synthetic Helios documentation for the `northwind` tenant. Version `v2`. Not real product documentation.

<!-- page: 1 -->

## Overview

<a id="overview"></a>

Helios 2.0 organises work into workspaces, projects and tasks. A workspace owns members, guest access, integrations and billing. Projects can use List, Board or Timeline views without changing the underlying tasks.

## Create a workspace

<a id="create-a-workspace"></a>

Sign in at app.helios.example and choose Create workspace. Enter a workspace name, choose the US or EU data region, and invite at least one other owner. The region cannot be changed after the workspace is created.

## Invite your team

<a id="invite-your-team"></a>

Open Settings > Members and choose Invite people. Pick Member, Viewer or Guest before sending. Guests only see projects they are explicitly added to and cannot open billing or admin settings.

<!-- page: 2 -->

## Create your first project

<a id="create-your-first-project"></a>

Open Projects and choose New project, or start from a template in the project gallery. Choose List, Board or Timeline. A task can have an assignee, due date, labels, attachments and a priority.

## Invite guests

<a id="invite-guests"></a>

Guests are external collaborators. Add a guest to a project from the project Members tab. Guests can comment and upload files, but they cannot create projects, invite other people or view the workspace member directory.

<!-- page: 3 -->

## Use a template

<a id="use-a-template"></a>

Templates copy a project structure, including sections, task titles, checklists and custom fields. Open the project gallery, choose a template and select Use template. Template changes do not affect projects that were created earlier.

## Next steps

<a id="next-steps"></a>

Connect Slack or GitHub from Settings > Integrations. Import an existing backlog from CSV under Projects > Import. Workspace owners can also enable SAML SSO from Settings > Security.
