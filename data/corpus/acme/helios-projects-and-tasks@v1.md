# Projects, tasks and views

> Synthetic Helios documentation for the `acme` tenant. Version `v1`. Not real product documentation.

<!-- page: 1 -->

## Overview

<a id="overview"></a>

Projects contain tasks, and tasks can contain subtasks. Use projects for a team initiative and tasks for the individual units of work. Every task has a reference, status, assignee and optional due date.

## Projects and views

<a id="projects-and-views"></a>

List view is the default. Timeline view places tasks on a calendar using start and due dates. Board view groups tasks by status. You can switch views without moving or copying any data.

## Task fields

<a id="task-fields"></a>

A task stores a title, description, assignee, reporter, status, priority, due date and labels. Subtasks inherit the project but keep their own assignee and status.

<!-- page: 2 -->

## Status and workflow

<a id="status-and-workflow"></a>

The default workflow is Backlog, To do, In progress and Done. Admins can rename statuses and choose which status counts as closed. Moving a task to a closed status records the completion date.

## Comments and mentions

<a id="comments-and-mentions"></a>

Comments support @mentions and file attachments. Mentioned members receive a notification even if they do not follow the task. Edit history is available from the task menu.

<!-- page: 3 -->

## Saved views and export

<a id="saved-views-and-export"></a>

Filters can be saved as a personal or shared view. Export the current view to CSV from the view menu; exports include visible columns only.
